# 콘텐츠·커리큘럼 재설계 (2026-07-30)

근거: 나무위키 [한국사능력검정시험/학습 조언](https://namu.wiki/w/한국사능력검정시험/학습%20조언) (최종 수정 2026-07-21)

> ⚠️ 나무위키 본문은 CC BY-NC-SA 2.0 KR 이다. **문장을 옮겨 쓰지 않고**, 문서가 제시하는
> *사실(출제 비중·빈출 주제·연표 순서 등)* 만 참고해 카드/퀴즈를 자체 문장으로 작성한다.

## 1. 측정된 격차 — 이게 이번 재설계의 출발점

문서 2절: **전근대사 : 근·현대사 출제 비중 = 60 : 40**

현재 앱 상태(실측):

| 구분 | 전근대 | 근현대 | 현재 비율 | 목표 |
| --- | --- | --- | --- | --- |
| 학습일 | 20일 | 8일 | **71 : 29** | 60 : 40 |
| 카드 | 1,390 | 562 | 71 : 29 | 60 : 40 |
| 퀴즈 | 846 | 336 | 72 : 28 | 60 : 40 |

전근대가 약 11%p 과대, 근현대가 그만큼 과소하다. 28일 기준 **전근대 17일 / 근현대 11일**이 목표치다.

(전근대 = prehistory ~ late-joseon / 근현대 = open-port, colonial, modern)

## 2. 변경 원칙

문서 6절(수칙)·7절(빈출 팁)·8절(특수한 파트)에서 도출한다.

1. **줄인다 (6.1)** — 절대평가 80점이 목표이므로 "50문제 중 2문제 미만" 주제는 버린다.
   판단 근거는 감이 아니라 `src/data/exam-frequency.ts`(심화 기출 8회차 정답 선택지 실측)를 쓴다.
   빈출 0회 + 교과서 핵심도 아닌 카드가 감량 1순위.
2. **연계한다 (6.2)** — 단일 사건을 따로 외우게 하지 않고, 키워드에서 가지를 뻗게 만든다.
   → 신규 카드 유형 3종(§4)의 근거.
3. **사진을 지킨다 (8.1)** — 문화재(탑·불상·건축물·그림·도자기)는 사진 없이 학습이 불가하다.
4. **순서를 외우게 한다 (8.2)** — 연표형 문제는 인과관계로 묶어 제시한다.
5. **매회 나오는 파트를 비운 채 두지 않는다 (8.3)** — 세시풍속·전통놀이는 거의 매회 1문제.

## 3. 커리큘럼 재배분 (28일 유지)

- 전근대 20일 → **17일**: 빈출 낮은 단원을 통합해 3일 확보.
- 근현대 8일 → **11일**: 개항기·일제강점기·현대에 3일 배분.
- `DAY_PLAN`(`src/data/curriculum.ts`)의 `units` 묶음을 재구성한다. **단원 번호(1~90)는 유지**한다 —
  카드/퀴즈 id(`dNN-cNN`)와 오디오 파일명, `IMAGE_OVERRIDES`, 즐겨찾기가 모두 이 번호에 묶여 있다.
  즉 **재배분은 "어느 단원을 몇 일차에 배치할지"만 바꾸고 단원 자체는 유지**한다.
- `daySlug`는 일차 제목 기반이라 제목이 바뀌면 URL이 바뀐다. 기존 슬러그는
  `day-slug.ts`의 하위호환 맵에 남겨 색인된 URL이 깨지지 않게 한다.

## 4. 신규 카드 유형 3종

기존 `StudyCard`를 그대로 쓰고 제목 접두사로 구분한다(스키마 변경 없음).

### 4-1. 지역 연계 카드 — "시험마다 한 문제는 꼭 나온다"(6.2 예시 2)
한 지역에서 일어난 사건을 시대를 넘어 한 장에 모은다.
대상: 강화도, 평양, 제주도, 공주, 의주, 원산, 충주, 안동, 익산, 부여, 수원, 김해, 양산, 강릉.

### 4-2. 인물 연계 카드 (6.2 예시 3)
한 인물의 소속 단체·사건을 한 장에 모은다. 예: 김구 → 한인애국단·상해 임시정부·한국독립당·남북협상.

### 4-3. 연표/순서 카드 (8.2)
문서가 제시하는 인과 묶음을 그대로 학습 단위로 만든다.
- 신라의 삼국 통일: 살수대첩 → 안시성 → 나당동맹 → 황산벌 → 백제 멸망 → 백제부흥 → 백강 → 고구려 멸망 → 고구려부흥 → 매소성/기벌포 → 통일
- 후삼국 통일: 고려 건국 → 발해 멸망 → 공산 → 고창 → 견훤 유폐 → 신라 항복 → 일리천
- 조선 정치: 사화 → 예송 → 환국
- 임진왜란 / 정유재란 / 정묘·병자호란
- 외세 침입: 병인박해 → 셔먼호 → 병인양요 → 오페르트 → 신미양요 → 척화비 → **운요호**(척화비 이후)
- 근대 조약: 강화도 → 조일수호조규 → 조미수호통상 → 임오군란 → 제물포/조청상민 → 조일통상장정

순서 배열 퀴즈를 함께 만든다.

## 5. 비어 있는 필수 파트 보강

- **세시풍속·전통놀이 (8.3)** — 월별 세시풍속과 전통놀이-역사사건 연결
  (강강술래=임진왜란·이순신, 그네뛰기=춘향전, 차전놀이=안동·왕건/견훤, 놋다리밟기=안동·공민왕/홍건적).
- **유네스코 유산 (8.4)** — 세계문화유산·세계기록유산·무형문화유산 목록을 각각 카드화.
- **빈출 지문 (7절)** — 신라/고려 불교 인물, 서원, 조선 전기 사화, 조선 후기 환국,
  동예 특산물, 진흥왕 순수비 4기, 신문왕 관료전·녹읍, 광종, 정조 규장각 검서관,
  신민회 105인 사건, 광주학생항일운동·신간회, 국채보상운동(대구)/물산장려운동(평양).

## 6. 문화재 사진 정책 — 직전 작업과의 충돌 해소

2026-07-30 이미지 검토에서 사진 107건을 제거했다. 그런데 8.1은 **문화재는 사진 없이 학습 불가**라고 한다.
두 판단이 충돌하는 항목만 되살린다.

- **되살릴 대상**: 탑·불상·건축물·그림·도자기 등 "모양을 몰라 틀릴 수 있는" 문화재.
  예) `d43-c06` 부석사 무량수전, `d43-c07` 수덕사 대웅전.
- **제거 유지**: 인물 초상, 유적지 원경, 지도, 문서 사진 등 모양 자체가 출제되지 않는 것.
  (`d50-c07` 이황, `d11-c03` 풍납토성, `d32-c23` 5도 양계 지도 등)

Day 단위 작업 중 해당 일차에 문화재 카드가 있으면 이 기준으로 재판정한다.

## 7. 실행 방식 — Day 단위

설계(이 문서) 확정 후 **Day 1 → Day 28 순서로** 진행한다. 각 Day마다:

1. 그 일차의 단원 카드/퀴즈를 §2 원칙으로 감량·보강 (`src/data/content/days-*.ts`)
2. 필요하면 §4 신규 카드 추가, §6 기준으로 사진 재판정
3. `npm run validate:content` → `npx tsc --noEmit` → `npm run lint`
4. 변경된 카드의 음성 재생성 (§8)
5. 커밋 1개 (`Day N 콘텐츠 재설계`) → push

커리큘럼 재배분(§3)은 Day 작업 **이전에** 한 번에 수행한다 — 일차별 단원 구성이 먼저 정해져야
Day 단위 작업의 대상이 확정된다.

## 8. 음성(TTS) 재생성

- 파이프라인: `scripts/gen-audio.ts` → `edge-tts`(무료·로컬, API 키 불필요),
  보이스 `ko-KR-SunHiNeural`, rate `-8%` → `public/audio/cards/<카드id>.mp3` + `src/data/audio-manifest.ts`
- 현재 mp3 1,952개 = 카드 수와 동일.
- ⚠️ **선행조건: `edge-tts`가 현재 미설치다.** 설치 후에만 음성 갱신이 가능하다.
- 카드 **내용이 바뀌면 반드시 재생성**한다(낭독 텍스트가 카드 본문이므로).
  카드를 삭제하면 해당 mp3와 매니페스트 엔트리도 정리한다.
- 스크립트는 기존 파일을 건너뛰므로, 내용이 바뀐 카드만 `FORCE=1`로 개별 재생성한다.

## 9. 이번 재설계에서 하지 않는 것

- **단원 번호(1~90) 변경 금지** — id·오디오·이미지 오버라이드·즐겨찾기가 전부 묶여 있다.
- 나무위키 문장 복제 금지 (§ 상단 라이선스 주석).
- 강사·교재·인강 추천(문서 3·5절)은 학습 앱 콘텐츠가 아니므로 반영하지 않는다.
- 시험 당일 컨디션·시간 관리(6.3)도 카드 주제로 넣지 않는다.
